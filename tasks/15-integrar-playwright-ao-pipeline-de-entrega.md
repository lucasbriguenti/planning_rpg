# Integrar Playwright ao pipeline de entrega

## Objetivo
Fazer os testes E2E participarem do gate de qualidade de cada entrega.

## Subtarefas
- [ ] Configurar execução dos testes Playwright no pipeline.
- [ ] Definir política de bloqueio para falhas nos testes críticos.
- [ ] Publicar relatório de execução para acompanhamento do time.

## Critério de conclusão
Nenhuma entrega crítica passa sem validação dos testes Playwright definidos como obrigatórios.

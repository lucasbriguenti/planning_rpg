# Criar roteiro dos testes principais

## Objetivo
Definir passo a passo dos testes mais importantes para garantir o básico do produto.

## Subtarefas
- [ ] Escrever um roteiro simples para os fluxos principais.
- [ ] Descrever o resultado esperado em cada etapa.
- [ ] Validar o roteiro com Produto/Negócio antes de automatizar.

## Critério de conclusão
O time tem um roteiro único dos testes principais, fácil de entender por pessoas técnicas e não técnicas.

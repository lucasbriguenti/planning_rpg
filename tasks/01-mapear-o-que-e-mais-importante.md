# Mapear o que é mais importante testar

## Objetivo
Listar o que mais impacta o usuário se der problema.

## Subtarefas
- [ ] Levantar as partes principais do app: entrar, criar sessão, votar, revelar resultado e encerrar sessão.
- [ ] Marcar cada parte com prioridade: alta, média ou baixa.
- [ ] Registrar quais partes não podem falhar de jeito nenhum.

## Critério de conclusão
Existe uma lista simples, aprovada pelo time, com prioridades claras do que deve ser testado primeiro.

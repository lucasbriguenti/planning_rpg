# Criar fixtures e massa de dados para E2E

## Objetivo
Garantir previsibilidade dos testes com dados consistentes e reutilizáveis.

## Subtarefas
- [ ] Definir usuários e sessões padrão para cenários de teste.
- [ ] Criar helpers/fixtures para preparar e limpar dados de teste no Firestore.
- [ ] Documentar como executar os testes sem depender de preparação manual.

## Critério de conclusão
Os testes E2E iniciam sempre com massa de dados conhecida e podem ser reproduzidos com consistência.

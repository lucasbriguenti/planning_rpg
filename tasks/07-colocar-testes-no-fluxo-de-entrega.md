# Colocar testes no fluxo de entrega

## Objetivo
Fazer com que toda mudança passe por testes antes de ser liberada.

## Subtarefas
- [ ] Configurar execução automática dos testes a cada nova entrega.
- [ ] Definir regra de bloqueio quando teste importante falhar.
- [ ] Publicar resultado para o time acompanhar.

## Critério de conclusão
Nenhuma entrega segue adiante sem passar pelos testes definidos como obrigatórios.

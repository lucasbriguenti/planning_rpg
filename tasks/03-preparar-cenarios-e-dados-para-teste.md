# Preparar cenários e dados para teste

## Objetivo
Garantir que os testes sempre comecem do mesmo jeito e sejam confiáveis.

## Subtarefas
- [ ] Definir exemplos de usuários, sessões e histórias para usar nos testes.
- [ ] Criar cenários comuns e cenários de exceção.
- [ ] Documentar como resetar os dados quando necessário.

## Critério de conclusão
Os testes conseguem rodar com dados padronizados, sem depender de ajustes manuais.

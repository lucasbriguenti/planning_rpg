# Configurar estrutura base do Playwright

## Objetivo
Preparar o projeto para executar testes Playwright de forma padronizada.

## Subtarefas
- [ ] Instalar e configurar Playwright no repositório com estrutura de pastas para testes.
- [ ] Configurar projetos de execução (ex.: Chromium) e opções de retry/timeout.
- [ ] Criar comandos de execução local e em modo CI no `package.json`.

## Critério de conclusão
O projeto roda testes Playwright localmente e está pronto para execução automatizada em pipeline.

# Validar integração com Azure

## Objetivo
Reduzir falhas ao importar itens do Azure para dentro da sessão.

## Subtarefas
- [ ] Testar importação com dados corretos.
- [ ] Testar retorno quando o acesso está inválido.
- [ ] Testar retorno quando o item não existe.

## Critério de conclusão
A integração apresenta comportamento previsível e mensagens claras nos cenários principais e de erro.

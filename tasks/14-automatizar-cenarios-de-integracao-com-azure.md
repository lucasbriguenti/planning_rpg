# Automatizar cenários de integração com Azure

## Objetivo
Garantir previsibilidade da importação de work items via Azure em testes E2E.

## Subtarefas
- [ ] Cobrir importação com credenciais válidas e item existente.
- [ ] Cobrir falhas esperadas (PAT inválido e item inexistente) com validação de mensagens.
- [ ] Definir estratégia de mock/isolamento para evitar dependência externa instável.

## Critério de conclusão
A integração com Azure possui cobertura E2E dos cenários críticos, incluindo sucesso e erros comuns.
